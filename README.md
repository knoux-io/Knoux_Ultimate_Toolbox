## 🚀 Quick Start

### System Requirements

- **Operating System**: Windows 10/11 (64-bit)
- **Memory**: 4 GB RAM minimum (8 GB recommended)
- **Storage**: 1 GB free disk space
- **Processor**: Intel/AMD 64-bit processor
- **.NET Framework**: 4.8 or later
- **PowerShell**: 5.1 or later

### Installation

1. **Download** KNOX ULTIMATE TOOLBOX from the official repository
2. **Run as Administrator**: Right-click `INSTALL.BAT` and select "Run as administrator"
3. **Follow the Installation Wizard**: Choose your preferred installation options
4. **Launch**: Use the desktop shortcut or run `KNOX_MAIN_MENU.BAT`

### First Launch

1. **Run System Diagnostics**: Start with a complete system health check
2. **Review Results**: Analyze the diagnostic report
3. **Apply Optimizations**: Use the recommended optimizations
4. **Create Backup**: Set up your first system backup
5. **Explore Features**: Discover the full range of available tools
